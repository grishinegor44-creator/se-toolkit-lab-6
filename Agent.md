# AGENT.md

## Overview

This project implements a simple CLI-based LLM agent in `agent.py`.

At this stage, the agent performs only the basic request-response flow:

1. Accept a user question from the command line.
2. Send the question to an LLM through an OpenAI-compatible chat completions API.
3. Return a structured JSON response to stdout.

This is the foundation for later tasks, where the agent will be extended with tools and an agentic loop.

## Architecture

The current architecture is:

User question → `agent.py` → LLM API → JSON response

The agent does not use any tools yet. For Task 1, it only returns:

- `answer`: the text generated by the LLM
- `tool_calls`: an empty array

## LLM provider

This agent uses the Qwen Code API as the LLM provider.

Chosen model:

- `qwen3-coder-plus`

Why this provider and model were chosen:

- It is recommended in the lab instructions.
- It supports the OpenAI-compatible chat completions API.
- It is suitable for future tasks that require tool calling.
- It can be configured through environment variables instead of hardcoding credentials.

## Configuration

The agent reads its configuration from `.env.agent.secret`.

Required variables:

- `LLM_API_KEY`
- `LLM_API_BASE`
- `LLM_MODEL`

Example:

```env
LLM_API_KEY=your_api_key_here
LLM_API_BASE=https://your-provider.example/v1
LLM_MODEL=qwen3-coder-plus
